# Локальний AI-режисер експедицій

## Мета

Зробити повторні експедиції відмінними одна від одної, не дозволяючи генеративній моделі змінювати правила, нагороди, маршрут або прохідність гри.

## Рішення

Гра синхронно створює гарантовано прохідну експедицію та повну авторську fallback-картку. Якщо гравець уже увімкнув локального оповідача, той самий browser worker асинхронно генерує українську JSON-картку для точного маршруту. Валідатор приймає лише дозволені ситуації, настрої й палітри, рівно одну нотатку на кожну відому точку, короткі українські тексти та fingerprint, якого не було серед останніх десяти звітів.

Експедиція ніколи не чекає на модель. Успішна відповідь оновлює назву, причину, польові докази, дальній слід і рідкісну знахідку. Помилка, невалідний JSON або повтор залишають fallback без модального вікна. Завершена експедиція зберігає канонічний спогад і fingerprint у звіті; до наступного prompt потрапляють не більше п’яти останніх спогадів і десяти fingerprints.

## Межі першого етапу

- Локальна модель не визначає ресурси, pressure, силу інструментів чи геометрію світу.
- Немає embeddings, NPC-чату, сезонів або генерації зображень.
- Старі збереження без narrative продовжують працювати через детермінований fallback.
- Уся видима копія українською; сирий model output не потрапляє в UI.

## Перевірка

Unit-тести покривають схему, заборону вигаданих точок, новизну, fallback, пам’ять та writer lifecycle. Playwright перевіряє асинхронне оновлення HUD і польового доказу без блокування гри. Повний build і наявні desktop/mobile сценарії мають залишитися зеленими.
